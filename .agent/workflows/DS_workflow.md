---
description: Data Science Model Training Workflow
---

1.  **Feature Engineering**:
    Create relevant features from the cleaned data.
2.  **Split Data**:
    Split into training and testing sets.
3.  **Train Model**:
    Train models (e.g., Random Forest) using `DS` notebooks.
4.  **Evaluate Model**:
    Check accuracy, precision, recall, and F1-score.
5.  **Save Model**:
    Save the trained model as a `.pkl` file in `DS`.
